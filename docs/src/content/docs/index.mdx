import { Card, CardGrid, LinkCard } from '@astrojs/starlight/components';

```python
import maybempi

MPI = maybempi.get_mpi()  # mpi4py.MPI under mpirun/srun, a serial stand-in otherwise
comm = MPI.COMM_WORLD
total = comm.allreduce(local_total, op=MPI.SUM)
```

<CardGrid>
	<Card title="No MPI in serial runs" icon="rocket">
		Importing `mpi4py.MPI` starts MPI, which costs close to a second. maybempi decides from the
		launcher's environment variables and never imports mpi4py in a serial run.
	</Card>
	<Card title="One code path" icon="random">
		The stand-in has the module constants and communicator methods of mpi4py, with the results
		MPI gives on one process.
	</Card>
	<Card title="Loud when unsupported" icon="warning">
		Methods the stand-in does not implement raise `AttributeError` instead of silently doing
		nothing.
	</Card>
	<Card title="No dependencies" icon="puzzle">
		Pure Python. mpi4py is only needed for MPI runs, NumPy only for array buffers.
	</Card>
</CardGrid>
